# Схема записи книги

Каждая книга - объект в `data/books.js` (массив `window.LIBRARY`).

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `id` | string | да | Уникальный, формат `b0001`. Не переиспользовать после удаления. |
| `title` | string | да | Название как на обложке. |
| `originalTitle` | string | нет | Оригинальное название для переводных изданий. |
| `author` | string | да | `Имя Фамилия`. Несколько авторов через `, `. Если нет - `Без автора`. |
| `authorSort` | string | нет | `Фамилия, Имя` для сортировки. Генерится автоматом, если пусто. |
| `year` | number \| null | нет | Год издания этого экземпляра. |
| `publisher` | string | нет | Издательство. |
| `language` | string | да | ISO-639-1: `ru`, `en`, `kk`, `de`... |
| `genres` | string[] | да | 1-3 жанра из справочника ниже. |
| `tags` | string[] | нет | Свободные метки: `подарок`, `с автографом`, `первое издание`. |
| `pages` | number \| null | нет | Объём. Влияет на ширину корешка в виде «Полка». |
| `isbn` | string | нет | Только цифры и X. Нужен для автоподтяжки обложки. |
| `series` | string \| null | нет | Название цикла. |
| `seriesIndex` | number \| null | нет | Номер в цикле. |
| `shelf` | string | да | ID ячейки стеллажа: `"<секция>-<полка>"`, например `4-6`. Секции 1-4 слева направо, полки 1-6 сверху вниз. |
| `status` | enum | да | `read` \| `reading` \| `unread`. |
| `rating` | number | нет | 0-5, 0 = не оценено. |
| `cover` | string | нет | URL или путь `covers/b0001.jpg`. Пусто - рисуется обложка-заглушка. |
| `notes` | string | нет | Личная заметка. |
| `addedAt` | string | да | `YYYY-MM-DD`. |
| `photoSource` | string | нет | Имя исходного фото, чтобы можно было перепроверить. |
| `confidence` | enum | нет | `high` \| `low`. `low` - корешок читается плохо, нужна перепроверка. |

## Справочник жанров

Художественная: `Классика`, `Современная проза`, `Фантастика`, `Фэнтези`, `Детектив`, `Триллер`, `Поэзия`, `Драматургия`, `Детская`, `Young Adult`, `Магический реализм`, `Исторический роман`, `Приключения`

Нон-фикшн: `Бизнес`, `Стартапы`, `Экономика`, `Психология`, `Философия`, `История`, `Биография`, `Наука`, `Технологии`, `Медицина`, `Дизайн`, `Саморазвитие`, `Политика`, `Религия`, `Путешествия`, `Кулинария`, `Стартапы`, `Искусство`, `Справочник`, `Учебник`

Новый жанр добавлять только если ни один из списка не подходит, и сразу дописывать сюда.
