# Домашняя библиотека

Каталог домашней библиотеки: поиск, жанры, карта физического стеллажа.
Статика без сборки - открывается двойным кликом по `index.html` или с любого статик-хостинга.

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка приложения |
| `assets/styles.css` | Дизайн-система, светлая и тёмная темы |
| `assets/app.js` | Поиск, фильтры, четыре вида, экспорт CSV |
| `data/books.js` | Каталог книг. Единственный файл, который растёт |
| `data/cells.js` | Карта стеллажа: 4 секции × 6 полок |
| `data/schema.md` | Схема записи книги и справочник жанров |
| `covers/` | Сканы обложек, если захочется добавить |

## Координаты стеллажа

Секции нумеруются **1-4 слева направо**, полки **1-6 сверху вниз**.
ID ячейки - `"<секция>-<полка>"`. Правая нижняя ячейка с книгами - `4-5`.

Вид «Стеллаж» повторяет реальную стенку: клик по ячейке показывает её содержимое.
Так книга находится не только в каталоге, но и рукой на полке.

## Виды

- **Стеллаж** - карта всех 24 ячеек, видно прогресс оцифровки
- **Обложки** - сетка с генеративными обложками
- **Полка** - корешки в ряд, ширина пропорциональна объёму
- **Список** - плотная таблица

## Процесс пополнения

1. Фото ячейки целиком + крупные планы книг, чьи корешки не читаются.
2. Записи добавляются в `data/books.js` с `shelf` = ID ячейки.
3. Всё, что прочитано неуверенно, помечается `confidence: "low"`.
   Фильтр **«Требуют проверки»** в шапке показывает такие книги списком.

Исходные фото лежат в `photos/` и в git не попадают - см. `.gitignore`.
